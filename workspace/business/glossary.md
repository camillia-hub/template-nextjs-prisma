# Business glossary

Use these terms in code, UI copy and conversations. Add a row when the domain gains
a concept; never invent synonyms.

| Term | Definition |
| --- | --- |
| Tenant | A customer organization; owns all data created by its users. |
| User | A person with login credentials; may belong to several tenants. |
| Membership | The link between a user and a tenant; carries the role. |
| Role | `owner`, `admin`, `member` or `viewer`; governs permissions. |
| Plan | The subscription tier of a tenant: `free`, `pro` or `enterprise`. |
| Seat | One active membership, counted for billing on paid plans. |
| Invoice | The billing document issued per subscription period. |
| Project | The core container object of the product; belongs to a tenant. |
